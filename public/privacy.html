Foldwink Privacy

Foldwink stores gameplay progress on this device only. Optional anonymous measurement is off until you explicitly allow it in the app.

Local data

Stats, streaks, tutorial state, and the cosmetic supporter badge stay in browser storage on this device. There are no accounts and no cloud sync.

Optional anonymous measurement

If configured and consented to, Foldwink sends only coarse custom events such as menu views, mode starts, wins/losses, share clicks, support-link opens, and privacy choices.

Foldwink does not send puzzle text, card text, category text, puzzle IDs or titles, raw URLs, referrers, user identifiers, free text, timestamps, or cross-site tracking data.

Provider

When enabled, Foldwink loads Umami in manual-event mode only after consent.
