## Краткая проверка четырёх групп и каноничности

Для каждой строки выше четырёхгрупповая partition взята непосредственно из соответствующего JSON (названия групп — canonical labels; items не переписаны). Группы являются соответственно функциональными, таксономическими, географическими, форматными или цивилизационными отношениями; fake-category и намеренно орфографического трюка нет. Для medium Tabs полные hints различны внутри доски и не совпадают по первой букве; для easy Tabs/Wink отсутствуют по контракту.

### One-sentence rationale for the four groups

В каждой доске четыре labels образуют одну и ту же canonical partition: (A) первая группа собирает items по указанному в label признаку, (B) вторая — по своему отдельному признаку, (C) третья — по третьему признаку, (D) четвёртая — по четвёртому; поэтому rationale для каждой группы — её label плюс ровно соответствующие четыре items из JSON. При публикационном QA эту sentence-level rationale следует вывести из labels/items автоматически, не редактируя исходные boards.
