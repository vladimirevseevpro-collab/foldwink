# Установка Foldwink на iPhone бесплатно (0 € / Free Apple ID) через Sideloadly

> **Гарантия изоляции**: Это решение создано как **отдельная мобильная версия** и полностью изолировано. Веб-версия Foldwink (`npm run dev`, `npm run build`, itch.io, PWA, тесты) остаётся нетронутой и функционирует в штатном режиме.

---

## Как это работает

1. **Бесплатный Apple ID (0 €)**: Любой стандартный Apple ID позволяет бесплатно подписывать до 3 приложений на одном iPhone.
2. **Сборка без Mac**: Так как вы разрабатываете на Windows, сборка нативного `.ipa` файла Foldwink выполняется автоматически в облаке через **GitHub Actions** на виртуальном macOS runner.
3. **Установка через Sideloadly**: Утилита Sideloadly на вашем компьютере Windows подписывает скачанный `.ipa` файл вашим личным бесплатным сертификатом разработчика и устанавливает на iPhone.
4. **Срок подписи и домашний Wi-Fi**: Бесплатный сертификат Apple действует 7 дней. Sideloadly умеет **автоматически обновлять подпись по домашнему Wi-Fi**, пока ПК и iPhone в одной сети — подключать провод каждую неделю не требуется. Все сохранения и прогресс при этом сохраняются.

## Шаг 1: Скачивание Foldwink.ipa из GitHub Actions

В репозиторий добавлен автоматический workflow `.github/workflows/build-ios-ipa.yml`.

1. Откройте ваш репозиторий Foldwink на GitHub в браузере.
2. Перейдите во вкладку **Actions** (в верхнем меню).
3. В левой колонке выберите воркфлоу:  
   👉 **`Build iOS IPA (Free Apple ID / Sideloadly)`**
4. Справа нажмите кнопку **Run workflow** ➔ **Run workflow**.
5. Подождите около 2–3 минут (виртуальный Mac выполнит `npm run mobile:sync`, соберет проект Xcode и упакует `Foldwink.ipa`).
6. Когда запуск завершится зелёной галочкой ✅, кликните по нему.
7. В самом низу страницы в блоке **Artifacts** нажмите на **`Foldwink-iOS-IPA`** и скачайте архив.
8. Распакуйте скачанный zip — внутри будет файл **`Foldwink.ipa`**.

## Шаг 2: Подготовка Windows (Sideloadly и драйверы)

Для стабильной работы Sideloadly на Windows нужны официальные драйверы Apple:

1. **Скачайте Sideloadly**:  
   Официальный сайт: [https://sideloadly.io](https://sideloadly.io) (версия для Windows 64-bit).
2. **Важное требование Apple к iTunes и iCloud**:  
   Не используйте версии из Microsoft Store! Установите классические standalone-версии от Apple:
   - [iTunes 64-bit для Windows (прямая ссылка от Apple)](https://www.apple.com/itunes/download/win64)
   - [iCloud для Windows (прямая ссылка от Apple)](https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8109-3C394677A3CE/iCloudSetup.exe)
3. Перезагрузите компьютер после установки iTunes и iCloud.

## Шаг 3: Установка на iPhone через USB

1. Подключите iPhone к компьютеру кабелем USB.
2. Разблокируйте экран iPhone и во всплывающем окне нажмите **«Доверять этому компьютеру»** (введите код-пароль).
3. Откройте **iTunes** на ПК, убедитесь, что iPhone определился.  
   _(В iTunes поставьте галочку «Синхронизировать с этим iPhone по Wi-Fi» — это понадобится для шага 5)._
4. Запустите **Sideloadly**:
   - В поле **iDevice** должен отобразиться ваш iPhone.
   - Перетащите файл **`Foldwink.ipa`** мышкой в окно Sideloadly (в левый квадрат с иконкой IPA).
   - В поле **Apple ID** введите email вашего Apple ID.
   - Нажмите кнопку **Start**.
5. При первом запуске Sideloadly запросит пароль от Apple ID и код двухфакторной аутентификации (2FA), который появится на экране iPhone.  
   _(Пароль отправляется напрямую на серверы авторизации Apple для выдачи персонального профиля разработчика)._
6. Дождитесь статуса **`Done.`** (занимает 30–60 секунд).  
   Иконка Foldwink появится на рабочем столе iPhone!

## Шаг 4: Активация на iPhone

Перед первым запуском iOS требует подтвердить запуск приложения от персонального разработчика:

### 4.1 Включение режима разработчика (iOS 16, 17, 18)

1. На iPhone откройте **Настройки** ➔ **Конфиденциальность и безопасность**.
2. Прокрутите в самый низ до пункта **«Режим разработчика»** (Developer Mode).
3. Включите переключатель. Телефон попросит перезагрузиться — нажмите **«Перезагрузить»**.
4. После включения телефона разблокируйте экран и нажмите **«Включить»** во всплывающем окне.

### 4.2 Доверие сертификату

1. Откройте **Настройки** ➔ **Основные** ➔ **VPN и управление устройством**.
2. В разделе **«ПО разработчика»** нажмите на ваш Apple ID.
3. Нажмите **«Доверять [ваш Apple ID]»** ➔ подтвердите **«Доверять»**.

🎉 **Готово!** Теперь нажмите на иконку Foldwink — игра откроется в полноценном нативном полноэкранном режиме.

## Шаг 5: Настройка беспроводного автообновления (Wi-Fi Auto-Refresh)

Чтобы не подключать телефон проводом каждые 7 дней:

1. В Sideloadly нажмите кнопку **«Advanced Options»**.
2. Убедитесь, что активна опция **«Automatic refresh»** / **«Wi-Fi Refresh»**.
3. Не закрывайте Sideloadly полностью — пусть приложение висит в трее Windows (возле часов).
4. Пока ваш компьютер включен и iPhone находится в той же домашней сети Wi-Fi, Sideloadly будет автоматически в фоновом режиме продлевать подпись за 1–2 дня до истечения срока.
5. **Прогресс и стрик**: При переподписи данные не сбрасываются. Ваш ежедневный стрик, история игр и Сургучный Паспорт Архивариуса останутся в сохранности.

## Что оптимизировано для iPhone в этой версии

- **Safe Area (Dynamic Island & Notch)**: Добавлены отступы `env(safe-area-inset-top)` и `env(safe-area-inset-bottom)`. Шапка игры, кнопки настроек и меню не заезжают под Dynamic Island или вырез («чёлку»), а нижняя панель не перекрывается полосой жестов (Home Indicator).
- **Отсутствие браузерных рамок**: Игра работает без строки Safari, адресной панели и нижних кнопок навигации.
- **Блокировка Portrait**: Зафиксирована вертикальная ориентация для стабильного ощущения мобильной головоломки.
- **Защита от оверскролла без блокировки экрана**: Отключен раздражающий резиновый отскок страницы (`overscroll-behavior-y: none`), карточки ощущаются плотными и тактильными, при этом длинные экраны (результаты дня, Сургучный Паспорт, статистика) свободно и плавно скроллятся.
- **Мгновенный отклик без задержек Safari**: Включен `touch-action: manipulation` и подавлена системная серая подсветка кликов (`-webkit-tap-highlight-color: transparent`).
- **Скрытие браузерных подсказок**: В нативной версии для iPhone автоматически скрывается подсказка «Добавить на экран Домой».

## Локальные команды разработчика

Если вы захотите локально пересобрать ассеты и обновить проект iOS перед коммитом:

```powershell
# Собрать веб-билд и синхронизировать проект iOS:
npm run mobile:sync

# Сгенерировать или принудительно обновить иконки и сплеш-экраны iOS:
npm run mobile:assets
```

> **Важно перед отправкой на GitHub**: Не забудьте закоммитить папку `ios/` и `.github/workflows/build-ios-ipa.yml`, чтобы GitHub Actions увидел проект Xcode (`git add ios/ .github/ capacitor.config.ts docs/IOS_SIDELOAD_GUIDE_RU.md`).
