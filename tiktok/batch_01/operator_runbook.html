Operator Runbook — Batch 01

Пошаговый документ для человека-оператора. Печатайте его или держите во втором окне. Весь батч — меньше часа активной работы, распределённой на 8 дней.

Prerequisites

  • Channel Setup шаги 1–9 выполнены (аккаунт = Business)
  • TikTok Studio открыт на tiktok.com/tiktokstudio, залогинены как Foldwink (desktop, используется для upload + schedule)
  • Мобильное приложение TikTok установлено и залогинено как Foldwink на телефоне, который остаётся у оператора — non-optional. Pin-comment и pin-to-profile не работают на desktop TikTok по состоянию на апрель 2026; оба требуют мобильного приложения.
  • Терминал открыт в C:\AI\neural-void.com\foldwink
  • File explorer открыт в tiktok\batch_01\exports\ и tiktok\batch_01\covers\

Per-post flow (≈6 мин на пост)

Повторяется для каждого id в publish_queue.json. Используйте scheduled slot из очереди — не публиковать сразу, если это не в пределах 15 минут от слота.

1Pre-flight клипа30 с

Откройте MP4 в окне размером с телефон и просмотрите один раз. Отклонить и взять резерв, если:

  • Первая секунда — чёрный экран, логотип, меню
  • Текст overlay обрезан 140 px safe-зоной TikTok UI (сверху/снизу)
  • Аудио сломано или тишина там, где должен быть SFX
  • Cover-кадр нечитаем на телефонной thumb

Если отклонили — берите резерв из publish_queue.json ("reserve": true) и начинайте с шага 1 заново.

2Copy caption в буфер5 с 
npm run tiktok:prep -- <N>

<N> = 1 для post-01, 10 для post-10, r2 для post-r2 и т.д. Скрипт печатает caption+hashtags и кладёт их в буфер.

3Upload в TikTok Studio2 мин
  1. TikTok Studio → Upload → выбрать MP4 из tiktok\batch_01\exports\.
  2. В поле caption: Ctrl+V. Caption и хэштеги лягут одним блоком.
  3. Open "More options" → Cover → Edit cover.
  4. Upload соответствующий JPG из tiktok\batch_01\covers\ (тот же stem имени). Не давайте TikTok auto-pick.
  5. Disclosure: Disclose video contents оставить off, если TikTok не требует.
  6. Comments / duet / stitch: все три ON. Off на Batch 01 убивает тест.
  7. Allow AI-generated label: OFF.
4Schedule30 с
  1. Scroll до Schedule video, toggle ON.
  2. Дата+время: скопируйте scheduled_slot_human из очереди (напр. "Mon 2026-04-27 · 7:30 PM ET").
  3. Убедитесь, что таймзона в TikTok Studio совпадает с ET. Если показывает локальную CET — конвертируйте ET в CET (ET + 6 ч в DST) и введите CET.
  4. Click Schedule. Клип в Scheduled posts.
5Подготовить pinned reply к publish time30 с

Держите терминал открытым до слота:

npm run tiktok:prep -- <N> --field=pinned

Не запускать сейчас — команда наготове, запустить в точный момент публикации.

6В слот публикации — опубликовать pinned комментарий1 мин, LIVE, мобильное приложение обязательно

TikTok публикует видео автоматически в слот. Pinned author comment — руками, и обязательно с мобильного приложения TikTok, не с TikTok Studio / desktop. По состоянию на апрель 2026 закрепление комментариев не доступно на desktop — только в мобильном app.

  1. На desktop: обновите опубликованный пост в аккаунте. Подтвердите, что live.
  2. Запустите готовую команду (шаг 5). Pinned reply в буфере desktop.
  3. Вставьте pinned reply в окно комментария под постом на desktop и отправьте. (Писать коммент с desktop можно — только pin-операция требует mobile.)
  4. На телефоне: откройте app Foldwink → тот же пост → значок комментариев → проскрольте к своему только что отправленному комментарию → долгое нажатие (~1 сек) → во всплывающем меню тапните Pin comment.
  5. Всё ещё на телефоне: лайкните свой pinned комментарий (сеет comment-блок как активный).
Лимиты и подводные камни:
  • Только один pinned комментарий на пост. Новый pin автоматически снимает предыдущий — это документированное поведение и используется как swap-механизм для pinned_comment_alt.
  • Пинить может только создатель видео — делегирования нет.
  • Deadline: в пределах 2 мин от публикации. Поздний pin теряет большую часть алгоритмического эффекта.
7First-hour follow-up5 мин активно за 60 мин
  • Ответить на 3–5 первых живых комментариев в первые 15 мин (desktop или mobile — что под рукой).
  • Никакого copy-paste. Каждый ответ визуально разный.
  • Если кто-то пишет своё время в "drop your time" — отвечайте своим временем, не просто ❤️.
  • Если в 30 мин никто не комментирует — свап на pinned_comment_alt:
    1. На desktop запустить node scripts/tiktok-prep.mjs <N> --no-copy --field=pinned и вручную скопировать значение pinned_comment_alt из publish_queue.json (хелпер сейчас копирует primary — для alt открыть JSON и взять alt-строку).
    2. На телефоне: опубликовать alt новым комментарием и запинить его. Новый pin автоматически снимет предыдущий.

Не отвечать троллям. Не прятать. Пусть лежат.

Daily monitoring (5 мин в день)

Каждое утро, TikTok Studio → Analytics, записать для каждого live-поста:

  • watch_time_sec_avg
  • completion_rate
  • comments
  • shares
  • profile_visits
  • bio_link_clicks (в post-specific analytics вкладке)

Записать в tiktok/batch_01/reports/day_N_numbers.md или простой xlsx. Не переинженирить — нужно ровно столько данных, чтобы выбрать Batch 02 winners.

Decision gates (сработало одно — действовать)

Gate A — Day 2 morning: opener health

Проверить post-01 и post-10 (оба были live за ночь). Если у любого из них:

  • completion_rate < 35 %, и
  • comments < 3,

рассмотреть swap main-слота дня (сейчас post-02) на резерв. Наиболее близкий — post-r3 (альт post-02, другой пазл).

Gate B — Day 3: format signal

К концу Day 2 — 4 поста live. Ранжировать по watch-time. Если топ-2 из одного bucket (например, оба near-fail), пропустить в следующие 24 ч клипы из других bucket-ов и взять резерв из победившего.

Gate C — Day 5: curiosity-click convert

Проверить post-10: ratio bio_link_clicks / profile_visits. Если >15 % — это north star для Batch 02, масштабировать curiosity-click клипы. Если <5 % — bottleneck в самой bio-ссылке (скорее всего, itch.io mobile load), чиним воронку, а не видео.

Gate D — Day 8 evening: финальный call

После публикации post-09 и 12 ч аналитики:

  1. Выбрать топ-3 клипа по weighted-score: watch_time × 0.4 + completion × 0.3 + (comments/views) × 0.2 + (profile_visits/views) × 0.1.
  2. Запинить все три на профиле (см. Channel Setup §7).
  3. Написать дебриф на одну страницу: tiktok/batch_01/reports/batch_01_debrief.md с гипотезами победителей и брифом Batch 02.

Emergency stops

Остановить публикации и не продолжать батч, если сработало любое из:

  • TikTok пометил пост за community guidelines — пауза, прочитать пометку перед следующим постом.
  • Аккаунт получил "unusual activity" — пауза 48 ч, ничего больше.
  • Клип получил 100K+ views за <2 ч — не добавлять новые посты в этот день. Over-posting на горячем клипе — #1 причина self-sabotage вирала. Дайте дышать.
  • itch.io 404 или down — убрать bio-ссылку до следующего поста; host-locally fallback вне scope Batch 01.
