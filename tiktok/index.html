Быстрые команды

Clipboard helper (scripts/tiktok-prep.mjs)

Читает tiktok/batch_01/manifests/publish_queue.json и кладёт нужное поле в буфер обмена.

  • npm run tiktok:prep -- 1 — caption + hashtags для post-01
  • npm run tiktok:prep -- 1 --field=pinned — pinned reply для post-01
  • npm run tiktok:prep -- r2 --field=all — все поля резерва r2, форматированно
  • npm run tiktok:prep -- 3 --field=cover — cover text для post-03

Поля: post (default, caption + hashtags), caption, pinned, cover, hashtags, url, all. Флаг --no-copy печатает без записи в буфер.
